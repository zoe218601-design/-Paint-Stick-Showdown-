# Paint Stick Showdown · 地牢章节

在原版提取的 Three.js r180、圆角几何体和武器模型基础上，继续扩展第三人称 PVE。
原游戏完整保存在 `legacy/index.html`，主菜单不运行旧爆破模式。

## 下载与运行

- 单文件试玩：`downloads/Paint-Stick-Showdown-play.html`，保存到电脑，用 Chrome / Edge 打开。
- 多文件项目：在项目目录执行 `python3 -m http.server 8765`，然后用桌面浏览器打开服务。
- 单文件采用内嵌普通脚本和样式，无 CDN、fetch、模块导入或服务器 API。
- 本机策略禁止 `file://` 浏览器自动测试，单文件通过静态 HTTP 服务验证；下载后的文件协议仍需桌面实测。

需要键盘、鼠标和 WebGL2，不含触屏操作。

## 当前内容

- 1-1 至 1-4，每小关 4 个主线房间，共 16 间；1-4 房间 4 为骷髅王战。
- 四套随机掩体模板。进入后锁门，清怪开门，经无怪通道前进；主线没有回头门。
- 每小关房间 2 右侧有可选支线：事件 A → 事件 B，可回到已清空的房间 2，不重复刷怪。
- 事件房按配置权重抽取商店、教官或祭坛。商店有四件补给，教官本局最多三个不同强化；祭坛强化步枪后锁门刷怪，也可不拿就离开。
- 房间 3 的灰色附加关卡门只预留接口，尚未开放。
- 骷髅刀兵：追击绕掩体，近身蓄力挥砍。骷髅弓手：准备后发箭，近身后退。骷髅法师：准备后发慢速魔法球。弹道可躲、被掩体阻挡。
- 怪物血量、伤害随小关和房间递增，公式位于配置表。
- 击败怪物有金币/回血球和弹药补给；每个小关结束额外恢复 30 生命、120 备弹。
- 骷髅王三阶段：60% / 30% 生命切换；召唤刀兵，巨型骷髅头从天而降。
- 砸击先有 1.5 秒红色落点预警，再下落 0.45 秒，命中造成 80 伤害；落点固定，可以跑开，不可用跳跃免疫。低血量时一次砸 3 处，活跃召唤物最多 10 只。
- 暂停、失败重开、章节通关、三种语言。所有本局状态在重开/刷新时清空。

## 操作与调试

WASD 移动，Shift 冲刺，空格跳跃，鼠标转向，左键射击，右键拉近瞄准，R 换弹，E 事件房互动，Esc 暂停。
浏览器不允许锁定鼠标时，可按住鼠标拖动转向。

F2 补满生命，F3 加 100 金币，F4 清怪，F6 提前开门，F7 跳房/通过通道，F8 进入骷髅王房间并补满弹药生命。
调试通关不等于普通流程难度验证。

## 数据与文件

- `js/config.js`：关卡怪物表、房间图、难度、BOSS 技能和掉落数值。
- `js/levels.js`：主线/事件房/通道、商店与教官奖励、本局进度。
- `js/room.js`：掩体模板、门、碰撞、寻路、旧房间资源回收。
- `js/monsters.js`：怪物模型和基础行为。
- `js/attacks.js`：箭矢、魔法球、红圈、落下骷髅头与碰撞清理。
- `js/boss.js`：骷髅王召唤和分阶段技能调度。
- `js/player.js`、`js/combat.js`：原第三人称控制与射击框架。
- `js/drops.js`：拾取物和带上限的粒子。
- `js/i18n.js`、`js/ui.js`、`css/game.css`：三语文字与界面。
- `vendor/three-bundle.js`、`js/weapons.js`：从原游戏保留的引擎和武器模型。

修改后执行 `python3 tools/build_standalone.py`，同步更新单文件下载版。

## 验证

已有 Playwright 与 Chromium 的环境中，先启动 8765 静态服务，再执行：

```sh
node tests/dungeon.cjs
GAME_URL=http://127.0.0.1:8765/downloads/Paint-Stick-Showdown-play.html node tests/dungeon.cjs
```

脚本验证实际射击、怪物攻击、掩体遮挡、16 间门/通道、支线返回、事件奖励、BOSS 预警/命中/躲避/召唤上限、失败重开和暂停。
自动遍历使用战斗 API 清怪验证流程，并非人工无调试打通；最终难度、手感、美术和性能需要试玩调优。

未实现后续职业技能、经验加点、复活、完整武器品阶/Buff 掉落、永久存档、工匠、其他章节。
