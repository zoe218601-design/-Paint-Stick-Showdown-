# Paint Stick Showdown · 地牢框架（第 1 步）

基于原仓库继续开发。原游戏完整保存在 `legacy/index.html`，主入口没有旧爆破模式。
Three.js r180、RoundedBoxGeometry 与颜料武器模型直接从原文件提取保留。

## 运行

无需打包、安装依赖、外部 CDN 或服务器 API。直接打开 `index.html`；也可在此目录运行：

```sh
python3 -m http.server 8765
```

使用支持 WebGL2 的桌面浏览器。第三人称过肩视角，靠墙自动拉近。
点击进入后鼠标转向；若浏览器拒绝锁定鼠标，可按住鼠标拖动转向。
WASD 移动、Shift 冲刺、空格跳跃、左键射击、右键瞄准、R 换弹、Esc 暂停。

第一步只有一把枪，所以暂不提供武器切换。清除四只骷髅刀兵后出口开启，走进金色门框完成试玩。
金色掉落提供金币，绿色掉落额外回血，走过去拾取。血量耗尽后可重试。

## 文件分工

- `js/config.js`：玩家、镜头、武器、怪物、房间和掉落数值。
- `js/i18n.js`：简中、英文、繁中文字。
- `js/player.js`：角色、移动、跳跃和第三人称相机。
- `js/room.js`：地牢、掩体、碰撞、寻路和出口。
- `js/monsters.js`：骷髅模型、追击与近战。
- `js/weapons.js`：保留的原版武器模型。
- `js/combat.js`：中心准星射线、掩体遮挡、弹药与换弹。
- `js/drops.js`：拾取物和有数量上限的短时粒子。
- `js/ui.js`、`css/game.css`：菜单、HUD、失败/完成界面。
- `js/main.js`：启动、输入、暂停和帧循环。
- `vendor/three-bundle.js`：从原版提取的引擎，避免直接编辑。

## 调试

对局内：F2 补血，F3 增加 100 金币，F4 清除当前怪物，F6 提前开门。
调试操作与正常战斗分开使用；F4 不代表实际射击测试。

## 范围与验证

只实现设计大纲第 1 步。多房间、职业技能、成长、复活、正式存档、工匠和 BOSS 尚未实现。
本局状态只保留在内存中，刷新或重试清空，不会读取或覆盖原游戏 localStorage。

通过 Chromium + WebGL 软件渲染验证启动、第三人称角色可见、换弹、失败重试、清怪开门、掉落拾取与完成界面。
本机浏览器策略阻止 `file://` 导航，因此双击路径尚未实际验证；代码使用普通相对路径脚本，没有模块导入或 fetch 依赖。
实际桌面鼠标手感、视觉效果和性能需要人工试玩调整。
